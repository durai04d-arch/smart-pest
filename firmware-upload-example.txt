ESP32 firmware upload contract
------------------------------
POST https://YOUR-VERCEL-DOMAIN/api/device-upload
Headers:
  Content-Type: audio/wav
  X-Device-Token: your-device-token
  X-Device-Id: ESP32-INMP441
Body:
  Raw WAV bytes (RIFF/WAVE header required; max 500 KB)

Note: the existing firmware may use a different endpoint path or JSON format. Update it to match this contract before flashing. Use server certificate validation rather than setInsecure() in production.
